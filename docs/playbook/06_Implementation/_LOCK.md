# 06 — Implementation Lock

## What "Locked" Means Here

How we work. These are team conventions, not product definitions. They change more often than upstream documents but still require discipline.

## Lock Criteria

1. [ ] Coding standards cover naming, folder structure, and testing rules.
2. [ ] Git workflow is practical for a solo developer (no bureaucracy).
3. [ ] Testing strategy defines what must be tested (Domain logic is non-negotiable).
4. [ ] Release process covers mobile stores and web deployment.

## Modification Rule

ADR required for changes that affect other developers or CI/CD. Solo workflow tweaks may be Draft → Locked without ADR.
