# 05 — Features Lock

## What "Locked" Means Here

Feature specifications. Each feature is a contract between Product and Engineering. A feature is Locked when Engineering can build it without asking Product questions.

## Lock Criteria (Per Feature)

1. [ ] Overview states the user problem and which lens(s) it serves.
2. [ ] Flow is step-by-step, covering happy path and one recovery path.
3. [ ] Screens list every screen with purpose, content, and entry/exit points.
4. [ ] Edge Cases cover at least: no data, too much data, offline, and user interruption.
5. [ ] The feature does not contradict any upstream document.

## Modification Rule

ADR required for changes to Locked features. New features may be added as Planned → Draft → Locked without ADR unless they require upstream changes.
