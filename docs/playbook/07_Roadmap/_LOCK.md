# 07 — Roadmap Lock

## What "Locked" Means Here

What we build and when. The most volatile layer, but MVP scope must be Locked to prevent scope creep.

## Lock Criteria

1. [ ] MVP scope is the smallest set of features that delivers the Brief's "done."
2. [ ] Every phase has a clear trigger (e.g., "v1 ships," "user feedback").
3. [ ] Known Unknowns list is honest about what we don't know yet.
4. [ ] No roadmap item contradicts `02_Principles.md` R3 (tier caps).

## Modification Rule

ADR required for MVP scope changes. Phase additions/reordering may be updated without ADR if they don't affect MVP.
