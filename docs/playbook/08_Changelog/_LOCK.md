# 08 — Changelog Lock

## What "Locked" Means Here

This directory is **append-only**. Entries are never edited after publication. Each entry is a historical fact.

## Lock Criteria

1. [ ] Entry has a version number and date.
2. [ ] Entry lists what changed and why.
3. [ ] Entry references the ADR that authorized the change (if any).

## Modification Rule

No ADR required to *add* an entry. Existing entries are immutable.
